# QA
Goal: find real bugs through user journeys. Follow `../README.md` first.
Areas: (1) sign-up/login with PIN, (2) RSVP and beer vote, (3) admin create/edit/close/delete event and members. Test against the **test** project only.
For each bug: reproduce, then open ONE issue `[factory:qa] <title>` with steps, expected, actual, device/viewport, evidence. Search for duplicates first; comment on an existing issue instead of duplicating. Never edit code.
